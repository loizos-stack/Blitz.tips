# Supercapper — scheduled post queue

A ready-to-paste posting schedule at a 4–6 hour cadence, covering the pre-launch
week and launch day, plus an evergreen rotation for the contest itself.

Read `supercapper-twitter-kit.md` first — it holds the claims table, the
compliance rules, and the numbers you're allowed to state. **Nothing here may
contradict it.** In particular: quote the $10,000 pool, never a fixed first
prize.

## How to use this

Paste each slot into a scheduler — X's own (Post → schedule), Buffer, or
Typefully. Nothing in this repo posts to X; there is no X integration and no
credentials, by design.

Attach the named asset from `public/marketing/`. Post copy without media only
where a slot says "no media" — an image or video roughly doubles reach on a
promotional post, and every asset listed here was rendered for this contest.

## Cadence

Four slots a day, ~4h40 apart, inside waking hours:

| Slot | Time (ET) | Why |
|---|---|---|
| A | 07:40 | Morning scroll, before the day's lines firm up |
| B | 12:20 | Lunch |
| C | 17:10 | **The money slot** — 2 hours before weekday main cards |
| D | 21:50 | Late, in-game, highest engagement for betting content |

Weekends add slot **E at 14:05**, ahead of the early card.

**A literal every-4-to-6-hours would post at 03:00.** That's deliberately not
scheduled. Round-the-clock cadence to a US sports audience buys nothing and
makes the account read as a bot, which is exactly what X's automation rules
look for. If the audience is European, shift every time in this file by +5 or
+6 and the shape still works.

Times avoid :00 and :30 — those minutes are crowded.

## Rotation rule

24 distinct posts below. Across the 8 days that's ~36 slots, so some posts run
twice. When one repeats it must be **at least 72 hours later and in a different
slot letter**, so nobody's timeline shows the same post at the same time of day.
The schedule tables already respect this; keep the rule if you extend them.

## Before you schedule any of this

- **Check the numbers against the live row.** $10,000 and 100 picks are in every
  second post here. The pool has already been edited once ($25,000 → $10,000)
  and the start once (Aug 3 → Aug 10). If either moves again, this file and
  every scheduled post move with it.
- **The assets say Aug 10.** They were re-rendered for the new date. Delete any
  older export you still have — the previous set said Aug 3.
- **P20 and E6 depend on registration closing Sep 27.** Confirm that's still the
  `registrationClosesAt` value before those slots run.
- **Compliance carries over** from `supercapper-twitter-kit.md`: 18+ / 21+ where
  applicable and a responsible-gambling line on the profile, never imply picks
  are income, and get authorization before paying to promote any of this.
